# 家里放哪儿：第一版设计

## 产品目标

个人离线手机 App，记录物品位置、搜索完整位置路径，并可选择设置保质期提醒。首页聚焦搜索和到期概览；第二页用固定网格可视化房间，用户可以涂画模块，房间为第 1 级，模块最多到第 3 级。

## 页面

- 首页：搜索、即将过期和已过期概览，不显示最近记录。
- 房间：房间卡片、网格布局、模块和物品卡片。
- 物品：全部物品、状态筛选、编辑和删除。
- 设置：提醒默认值、通知权限、本地数据管理。

## 关键规则

- 新增物品先选择是否设置保质期；不设置时不创建提醒。
- 保质期支持生产日期加时长自动计算，或直接填写过期日期。
- 默认提前 7 天提醒。
- 删除有内容的房间或模块时允许递归删除，但确认框必须显示内容数量和不可恢复提示。
- 数据模型预留稳定 ID，后续接入 SQLite 和本地通知。
