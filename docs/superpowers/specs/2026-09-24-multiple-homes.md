# 多家庭首页与房间导航

## 已实现

- 家通过稳定 ID 关联房间，物品与模块通过房间确定家庭；现有演示内容归入“我的家”。
- 当前家统计四项记录数，全局搜索包含家庭完整路径，分类全局共享。
- 支持创建、重命名和切换家；房间可新增、重命名，卡片含布局缩略图及包括后代物品的数量。
- 房间卡片、房间布局、二级模块、三级模块逐级进入/返回；家不占布局层级。
- 新增物品明确选择当前家房间，布局内默认当前位置；新物品自动分配直属空格，网格满时仍在直属列表可见。
- 日期用本地日历日，今天为 0，7/30 天统计均含今天且不含过期；前台恢复和午夜更新。
- 名称去除首尾空白、非空、最多 40 个字符；家名全局唯一，房间名在家内唯一。
- 空家庭、切换位置、删除最后一个房间有专门处理。不存在房间不会被默认访问。

## 边界

数据仍只在内存中。持久化、系统通知、布局编辑器、删除整个家和跨家庭搬移另行实现。

## 验证

领域行为测试、浏览器流程测试和手机/桌面截图，另运行 TypeScript 检查以及 Android/Web 导出。浏览器验证不等同于真机验证。
