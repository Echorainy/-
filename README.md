# 家里放哪儿

“家里放哪儿”是一款面向个人使用的家庭物品管理 App。它帮助你记录物品放在哪个家、哪个房间和哪个模块，在忘记位置时快速搜索；对于食品、药品等物品，还可以记录保质期并获得到期提醒。

项目基于 Expo 和 React Native，当前处于可在手机上试用的原型阶段。

## 当前功能

- 首页显示当前家庭名称、物品总数和到期统计。
- 支持创建、切换和重命名多个家。
- 每个家可以创建多个房间，并支持重命名和删除房间。
- 房间使用统一的 8×8 正方形布局。
- 房间内支持最多三级位置层级：房间、模块、子模块。
- 模块支持逐格编辑、点击选择、拖动选择、保存和取消。
- 模块支持 8 个暖色莫兰迪预置色，也支持输入 6 位 HEX 色值。
- 物品支持分类标签、房间和模块位置、无保质期、直接填写过期日期，或填写生产日期和保质期天数计算过期日期。
- 支持按物品名称、分类和位置搜索；全局搜索会覆盖所有家，普通物品列表只显示当前家。
- 支持编辑和删除物品、模块、房间及自定义分类。
- 删除包含内容的房间或模块前会显示确认提示。
- 支持本地到期提醒；提醒功能需要独立开发版或正式构建，Expo Go 预览环境不会启用系统通知。
- 首页、物品页、设置页和房间页使用统一的暖色家庭主题，并包含猫咪助手空状态和欢迎区。

## 在手机上试用

### 环境要求

- Node.js
- pnpm
- Android 或 iOS 手机
- 手机和电脑连接同一局域网
- 手机安装 Expo Go

### 启动开发服务器

```bash
pnpm install
pnpm start -- --lan --port 8085
```

启动后可以使用 Expo Go 扫描终端中的二维码，也可以手动打开终端显示的 `exp://` 地址。若电脑局域网地址为 `100.65.205.39`，示例地址为：

```text
exp://100.65.205.39:8085
```

如果手机无法连接：

1. 确认手机和电脑没有连接到不同的 Wi-Fi 或访客网络。
2. 暂时关闭 VPN、代理或防火墙中的局域网拦截。
3. 使用 `--tunnel` 启动 Expo，或改用手机热点。
4. 确认手机能够访问电脑的局域网 IP 和开发端口。

### 建议试用流程

1. 在首页切换或新建一个家。
2. 进入“房间”页，新建房间并打开房间卡片。
3. 新建模块，选择颜色并保存。
4. 进入“编辑布局”，点击和拖动选择网格，再保存布局。
5. 在房间或模块内记录物品，选择分类和位置。
6. 使用首页搜索检查完整位置路径。
7. 为物品设置过期日期，检查首页的 30 天、7 天和已过期统计。

## 浏览器预览

浏览器预览适合检查 UI 排版和基础交互：

```bash
pnpm start -- --web --port 8083
```

然后打开 [http://localhost:8083](http://localhost:8083)。浏览器端使用 `localStorage` 保存快照，手机原生端使用 SQLite 保存快照。

## 开发命令

```bash
# 安装依赖
pnpm install

# 启动 Expo
pnpm start

# 类型检查
pnpm typecheck

# 运行领域、布局、持久化和通知测试
pnpm test

# 运行浏览器验收测试
pnpm test:ui

# 导出 Android JavaScript bundle
node node_modules/expo/bin/cli export --platform android
```

## 数据说明

- Android 和 iOS 使用 SQLite 保存当前设备上的本地数据。
- Web 使用浏览器 `localStorage` 保存数据。
- 当前没有账号、云端同步、跨设备同步或多人协作。
- 删除房间或模块会连同其中的模块和物品一起删除，并且无法恢复。
- 数据快照兼容旧版本中没有模块颜色的记录，旧模块会使用默认鼠尾草色。
- Expo Go 中不会启用系统通知；需要独立开发版或正式原生构建验证通知权限和提醒效果。

## 项目结构

```text
App.tsx                 应用入口、全局状态和页面导航
src/domain.ts           家庭、房间、模块、物品和分类模型及业务函数
src/pages.tsx           首页、房间、布局网格、物品列表和设置页面
src/ItemForm.tsx        物品录入和编辑表单
src/grid-edit.ts        网格坐标、涂画和布局校验
src/persistence.ts      快照编码、解码和兼容处理
src/storage.ts          原生 SQLite 存储
src/storage.web.ts      浏览器 localStorage 存储
src/notifications.ts    到期提醒封装
src/ui.tsx              颜色、组件和页面样式
assets/                 猫咪助手图片资源
tests/                  单元测试和浏览器验收测试
```

## 当前范围外

- 删除整个家。
- 跨家搬移物品。
- 云端账号和同步。
- 多人共享和权限管理。
- 自定义网格行列数量。
- 图片识别、条码扫描和批量导入。
