# Project Instructions

## Global UI and Cat Mascot Design

- Before designing, implementing, reviewing, or changing any UI, page, component, interaction, or cat mascot image, read `docs/global-ui-design-spec.md`.
- Treat that document as the single source of truth for global colors, spacing, radii, typography hierarchy, page structure, component behavior, accessibility, responsive checks, and mascot proportions, palette, simplicity, prompt constraints, and validation.
- Preserve the established UI and mascot system across variants. Do not introduce a new style, palette, body proportion, interaction pattern, or level of detail without explicitly updating the design specification first.
- After implementation or generation, check the result against the specification, especially responsive layout, semantic status colors, accessibility labels, transparent background, silhouette clarity at mobile size, outline thickness, eye thickness, ear proportion, and simplified mouth and paws.
